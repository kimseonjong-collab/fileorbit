# Google Stitch UI Reference

The uploaded Stitch package is the visual reference for FileOrbit.

## Adopted V0.1 design language
- Deep navy Kinetic Grid surfaces
- Electric-blue primary actions
- Dense but readable dashboard cards
- Left navigation
- Clear safety/status badges
- Review-first interaction model

## Deferred Stitch screens
The Stitch package contains many concepts beyond V0.1 (HUD, RAM monitoring, AI rule editing, scheduled scan, DRM, Undo variants). They are intentionally deferred until Folder Doctor is proven against real work folders.

## V0.1 selected flow
Dashboard → Folder selection → Read-only scan → Folder Profile → structural recommendation → Dry Run.

No automatic filesystem mutation is enabled in this phase.
