# FileOrbit V0.4 Acceptance

## Release gate
V0.4 is acceptable for a Windows checkpoint build only when all items below pass.

### Folder Doctor / Folder Map
- [ ] Existing work root is selected explicitly by the user.
- [ ] Folder scan is read-only.
- [ ] Noise exclusions do not mutate disk content.
- [ ] Folder Map is persisted only after explicit approval.
- [ ] Drift between saved Folder Map sources and a later scan is visible.

### Downloads Organizer
- [ ] Downloads root is selected explicitly.
- [ ] Scanning does not move, rename, delete, or overwrite files.
- [ ] Recommendation, review, and hold states are distinguishable.
- [ ] Manual classification correction is stored locally.
- [ ] Per-file review decisions and overrides are scoped to Folder Map root + Downloads root.
- [ ] Re-scan retains decisions only for files still present.

### Move safety
- [ ] Move requires approved Folder Map.
- [ ] Move requires explicit per-file approval and final Move confirmation.
- [ ] Rust validates source under selected Downloads root.
- [ ] Rust validates target under approved work root.
- [ ] Parent-directory traversal and invalid relative path elements are rejected.
- [ ] Existing destination collision is rejected; overwrite is never silent.
- [ ] Same-volume move is journaled.
- [ ] Cross-volume fallback uses temporary copy + byte-size verification before source removal.
- [ ] Failed cross-volume source removal attempts rollback of the created destination.

### Journal / Undo
- [ ] Planned, moved, failed, undone, and undo_failed states are auditable.
- [ ] Move history survives app restart.
- [ ] Undo is available only while at least one successfully moved item remains effective.
- [ ] Undo collision stops that item rather than overwriting the original path.
- [ ] Failed Undo remains retryable after the external cause is resolved.
- [ ] Transaction detail exposes source, target, status, and error.

### Build / regression
- [ ] Frontend build passes.
- [ ] Rust/Tauri CI passes.
- [ ] Web Preview build passes.
- [ ] Web Preview clearly states that it uses demo data.
- [ ] Desktop safety copy describes V0.4 explicit Safe Move/Undo, not V0.1 read-only behavior.
- [ ] Windows installer is generated only at an explicit checkpoint request.

## Explicitly out of scope
Background file movement, scheduled file movement, automatic deletion, cloud file-content upload, and silent overwrite are not part of V0.4.
