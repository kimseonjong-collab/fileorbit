# V0.1 Acceptance Criteria

- User can select a root folder for analysis.
- Scan is explicitly started by the user.
- Scanner is read-only.
- Folder tree is displayed.
- Folder statistics include file count, total size, extension distribution, and modified-time summary.
- Folder profile includes representative filenames and extracted filename keywords.
- Common noise folders can be excluded (node_modules, .git, cache/temp/build outputs).
- Similar/ambiguous folder candidates are shown as recommendations only.
- A Dry Run view shows proposed structural changes without modifying disk.
- No file-system mutation API is enabled in V0.1.
